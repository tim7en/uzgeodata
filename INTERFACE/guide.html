For researchers exploring a catchment

Your first basin in five minutes.

  1. Find a basin. Search for a HYBAS or PFAF identifier such as 4120050220. The finder covers every level-12 basin at any map zoom.
  2. Read the result. Select a search result to open its monthly chart. Choose a variable to change the chart. Gaps mean no observation; snow is not suitable for trend analysis.
  3. Download the evidence. Download all monthly variables as CSV, or use Monthly data & metadata (JSON) to keep values, units, sources and limitations together.

Use the adjacent HydroATLAS attributes and Independent estimates tabs to compare sources. Upstream values already include basins above them and must not be added across basins.

For several basins, choose Draw area, drag a rectangle on the map, and choose a download. The Everything JSON includes the selected area, attributes, records and provenance.

Report on your own locations

On the main map, choose Upload points or polygons · basin reports in the Area of interest controls. Upload GeoJSON points, polygons or multipolygons, or a CSV with longitude,latitude,name columns. Use WGS84 decimal degrees. Files are processed in your browser; up to 100 locations and 5 MB are supported.

Each point matches its containing level-12 basin. If it falls outside the mapped boundary, the maximum snap distance controls whether it can be assigned to a nearby basin. Choose zero to disable nearby snapping. Polygons select every intersecting basin, including basins touched at the boundary. Their statistics describe whole basins, not just the uploaded polygon. A polygon report supports up to 100 intersecting basins.

Select a location and a monthly variable in the modal to compare local basin statistics with the combined upstream catchment. Shared upstream basins are counted once. Coverage is reported for missing observations; these are not replaced by zero. This assigns locations to published basins, rather than delineating a new catchment at an exact river outlet.

The same report works on a basin you select. Open any basin on the map and choose Basin & upstream report: no matching is involved, because the basin is the answer already — the report covers it and everything draining into it. Statistics are published for level-12 sub-basins, so a coarser basin is reported through every level-12 unit inside it.

The same report works on an area you draw. Choose Draw area, drag a rectangle, then Basin report for this area: the drawn shape is treated exactly as an uploaded polygon would be, so its statistics describe every level-12 basin it intersects, whole, rather than the shape itself.

Download PDF saves a report summary. Report & data (ZIP) also includes the complete JSON report, monthly CSV, original uploaded feature, matched and upstream basin boundaries, basin attributes and their dictionary. Repeat for each location or variable you need. The report retains the source information and limitations.

Download without the map

The API is a collection of public static JSON files. No API key is required.

  • Basin index and attribute catalogue
  • Example basin attributes and estimates
  • Monthly record index and example monthly record

Replace the example identifier with any basin ID from the index. Monthly arrays start in January of the first stated year and retain null months in place. The CSV leaves nulls empty. Download metadata alongside the CSV to preserve units and limitations.

When something is missing

Independent estimates and monthly records are published for level-12 basins. At coarser levels, zoom in and select a smaller basin. An absent estimate means it has not been published, not that its value is zero. If a request fails, retry after checking your connection.

Get help or report a problem

Open a GitHub issue. Include the page URL, basin ID, selected tab or variable, expected and actual behaviour, browser and screen size. For data concerns, attach the method and source release from the metadata. Do not include credentials or private station data.
