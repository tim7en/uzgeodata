UzGeoData · Public preview

Read the basin. Follow the evidence.

UzGeoData helps researchers explore the Amu Darya and Syr Darya systems across national boundaries. For 7,445 level-12 basins, compare published HydroATLAS attributes with independent open-data estimates, inspect monthly records for 2003–2022, and download values with their provenance.

This is an exploratory public preview. No atlas attribute has passed independent scientific reproduction. Independent estimates may use different source products, periods and methods from HydroATLAS; agreement is not a reproduction test. This portal is not an operational forecast or an allocation tool.

What is published

The basin catalogue describes 281 attributes. Estimate coverage varies by attribute and basin; missing estimates are explicitly pending. The monthly release includes completed extraction runs only. Ongoing temperature downloads are outside the launch snapshot.

Data are recorded in an append-only observation store. Corrections supersede earlier observations. The public view carries source releases, method identifiers, units, periods and basin geometry versions.

Snow and missing values

Snow is withdrawn from trend use. Regional missing months increase across 2003–2022, and the cause has not been established. Snow values remain available for inspection. Do not infer a snow trend from this preview.

A null is an unavailable observation, never zero. Annual means describe the observed months; annual totals are shown only for monthly fluxes with all 12 months observed.

Licences and reuse

Source datasets retain their own licences and attribution requirements. Inspect each attribute’s evidence and source catalogue before redistributing data. This project does not grant a blanket licence over third-party data. See the attribute catalogue for recorded source terms.

No repository-wide software licence has yet been declared. Public access does not itself grant unrestricted reuse of the code. Contact the maintainer through GitHub to request clarification.

How to cite

Cite the original dataset as well as the portal. Record the basin ID, attribute or variable, period, source release, method hash, download date and repository commit. The JSON download preserves metadata that a spreadsheet alone may lose.

UzGeoData contributors. UzGeoData: Amu Darya and Syr Darya basin atlas, public preview. https://github.com/tim7en/uzgeodata. Accessed [date], commit [SHA].

Maintenance and feedback

The project is maintained through tim7en/uzgeodata on GitHub. Report a data or interface issue with the basin ID, tab, attribute and downloaded method identifier. No service-level or update-frequency guarantee is made for this preview.
