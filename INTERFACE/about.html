UzGeoData · Public preview

Read the basin. Follow the evidence.

UzGeoData helps researchers explore the Amu Darya and Syr Darya systems across national boundaries. For 7,445 level-12 basins, compare published HydroATLAS attributes with independent open-data estimates, inspect monthly records covering 2003–2026, read whole-catchment statistics that aggregate everything draining into a basin, and download values with their provenance.

This is an exploratory public preview. No atlas attribute has passed independent scientific reproduction. Independent estimates may use different source products, periods and methods from HydroATLAS; agreement is not a reproduction test. This portal is not an operational forecast or an allocation tool.

What is published

The basin catalogue describes 281 attributes. Estimate coverage varies by attribute and basin; missing estimates are explicitly pending. The monthly release includes completed extraction runs only.

The record carries fourteen monthly variables for every basin: precipitation, actual and potential evapotranspiration, total runoff from ERA5-Land and runoff from TerraClimate, soil moisture, snow cover and snow water equivalent, minimum, mean and maximum temperature, climate water deficit, vapour pressure deficit, and the Palmer drought severity index. It spans 288 calendar positions from January 2003 to December 2026.

Calendar positions are not observations. How far a variable actually reaches is set by its source: ERA5-Land runoff and mean temperature run to August 2026, while the TerraClimate family ends at December 2024, the latest month that product has released. Nothing is extrapolated to fill the difference, and every series records where it ends. Check the release metadata and the history index for the deployed snapshot.

Alongside the per-basin record, the whole-catchment package aggregates the level-12 drainage network: area-weighted monthly means over everything upstream, sub-basin extremes, water-volume totals and derived morphology. It is published as one delta-encoded file per variable rather than as thousands of separate requests, with a checksum the page verifies before use.

Data are recorded in an append-only observation store. Corrections supersede earlier observations. The public view carries source releases, method identifiers, units, periods and basin geometry versions.

Snow and missing values

Snow is withdrawn from trend use. Regional missing months increase across the record, most visibly since 2017, and the cause has not been established. Snow values remain available for inspection. Do not infer a snow trend from this preview.

A null is an unavailable observation, never zero. Annual means describe the observed months; annual totals are shown only for monthly fluxes with all 12 months observed.

Licences and reuse

Source datasets retain their own licences and attribution requirements. Inspect each attribute’s evidence and source catalogue before redistributing data. This project does not grant a blanket licence over third-party data. See the attribute catalogue for recorded source terms.

No repository-wide software licence has yet been declared. Public access does not itself grant unrestricted reuse of the code. Contact the maintainer through GitHub to request clarification.

How to cite

Cite the original dataset as well as the portal. Record the basin ID, attribute or variable, period, source release, method hash, download date and repository commit. The JSON download preserves metadata that a spreadsheet alone may lose.

UzGeoData contributors. UzGeoData: Amu Darya and Syr Darya basin atlas, public preview. https://uzgeodata.uz. Source and releases: https://github.com/tim7en/uzgeodata. Accessed [date], commit [SHA].

Maintenance and feedback

The project is maintained through tim7en/uzgeodata on GitHub. Report a data or interface issue with the basin ID, tab, attribute and downloaded method identifier. No service-level or update-frequency guarantee is made for this preview.
