# Data and code reuse

Third-party data retain their original terms. The public catalogue and each
expanded estimate row record available source licences and catalogue links.
Verify those terms and attribution requirements before redistribution. A portal
download does not replace or broaden the source licence.

No blanket licence is granted here over the combined dataset. No repository-wide
software licence has yet been declared; public visibility is not an unrestricted
licence to reuse the code. Ask the maintainer through GitHub for clarification.

For research attribution, use `CITATION.cff` and cite the original products. Keep
the basin ID, attribute or variable, units, period, source release, method hash,
geometry version, repository commit and download date with your analysis.

The release is a public preview. Independent estimates are not reproduced
HydroATLAS results. Snow is withdrawn from trend use pending investigation of
increasing missing months across 2003–2022.
